# Movie Recommendation System

A content-based movie recommendation system built using Python.

## Overview

This project recommends movies based on similarity between movie features. It uses cosine similarity to identify movies that are most similar to a selected movie.

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn

## Concepts Used

* Vector Representation
* Cosine Similarity
* Data Preprocessing
* Recommendation Systems

## How It Works

1. Movie information is processed and converted into feature vectors.
2. Cosine similarity is calculated between movies.
3. The system identifies movies with the highest similarity scores.
4. Similar movies are recommended to the user.
